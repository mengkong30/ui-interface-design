# 视觉系统与验收规则

## 信息层级与字体

- 时间或核心指标应明显高于日期、单位、辅助说明。次要信息增加时，不通过把所有字体压小来容纳。
- 小屏减少文字比例，可用图标、简短数据和图表替代重复说明；仍保留必要的单位、状态与图例。陌生图标不要完全取代文字。
- 大标题的居中方式按设备与既有系统决定。手表可以屏幕为中心居中，右侧时间独立放置；检查两者是否相撞，不要把标题简单放在剩余空白中间。
- 数字与单位形成一组：统一视觉基线，单位贴近数值，避免单位漂在卡片远端。字体实际字面高度不等于文本框高度，导出后校正。
- 类似来电页，头像、姓名、辅助说明与操作区要形成连续阅读路径。头像可比辅助图标大，但不能把姓名和说明挤向边界。
- 中文标签使用支持中文的字体；从英文改成中文后重新核对宽度、居中和换行。

## 对齐与空间

- 天气等重复列采用相同列宽。时间、图标、温度共享同一中心线，而不是各自左对齐。
- 文字使用固定宽度居中，或依据实际文字宽度计算位置；内容变化后仍应保持对齐。图标不仅看画框，还要看可见轮廓的光学中心。
- 单行菜单名称垂直居中；双行菜单以“名称+摘要”整个文本组居中。二者不能机械使用同一文本起点。
- 卡片边距、图标底板、图标与文字间距共同决定舒展度。不要用放大图标填满空白，也不要过度嵌套底板制造厚重感。
- 菜单可显示部分下一项提示滚动，但应是有意义的露出；只露一点卡片上沿容易像裁切错误。若采用完整三项布局，用滚动指示补充可发现性。
- 上下滚动状态沿用相同卡片尺寸与节奏；末屏不能突然变疏或更换字体。

## 颜色与表面

- 按背景、表面、主操作、正文、次要文字、健康/进度、警示等角色分配颜色；同一语义跨页面一致。
- 深色背景上的小字号高饱和蓝字可能不够清楚。可保留蓝色按钮/进度条，把状态小字改为较亮的中性色或已定义的语义色。
- 强调色集中于关键数据、操作和少量图标。不要为达到“多于两色”给所有元素轮流染色。
- 插画和照片的自然色不必机械压成 UI 色板，例如天气太阳可用明亮黄色；先区分插画色与交互强调色，并遵循用户最终要求。
- 阴影、内阴影与微渐变需要在实际尺寸下仍有作用，不能靠大量阴影掩盖布局问题。

## 图标与 keyline

- 在实际目标尺寸绘制。32px 图标不能先放大三倍绘制，再假定缩回来会自动保留合适的视觉重量。
- 使用统一画板、安全留白和圆形、方形、横向、纵向 keyline。keyline 是光学平衡参考，不是所有轮廓必须占满同一矩形。
- 校正头部/躯干、车轮/车架、图形孔洞、细桥接处的重量。不同形状允许光学校正，使视觉面积、密度和重心接近。
- 用户选择面性时，使用真实填充轮廓。不要用越来越粗的描边冒充面性，尤其注意跑步、步行、骑行的连接处与关节。
- 统一端点、外角与内凹角的圆润程度。计时器顶部按钮、日历双耳与日期孔洞、音乐斜梁、铃铛底部常被遗漏。
- 圆角不能吞掉小孔洞或使相邻部件粘连。检查小尺寸识别度以及放大后的路径尖刺、自交和异常凹陷。
- SVG 圆弧的方向参数错误会产生内凹尖刺；不要以为弧线存在就等于圆角正确。
- 菜单/辅助图标和主视觉插画可使用不同尺寸等级；大头像或状态插画不必强行缩成32px。
- 替换主组件后检查实例缩放、覆盖值、底板位置与真实图形尺寸，避免画框变小而内部路径仍很大。

## 数据、天气与动效

- 多色圆环每一圈必须有明确指标、目标与计算依据。不得为了丰富画面虚构卡路里、目标或完成率；示例数据要标明。
- 睡眠阶段不能只靠相近蓝色让人猜。时间轴颜色与“色块+文字”图例一一对应，保证深睡、浅睡、快速眼动阶段可区分。
- 图表替代叙述时仍保留足够的读数与单位。摘要可以更简洁，详情页提供必要解释。
- 天气背景需让城市、温度与小时预报可读；统一遮罩和裁切策略，检查云层高光是否冲淡文字。避免背景与重复的大天气图标争夺注意力。
- 昼夜、晴雨等状态沿用相同结构，检查跨午夜时段与每列对齐。插画明亮、柔和、无描边是可选风格要求，不是所有天气产品的标准。
- 运动计时、呼吸节奏和测量状态可用动效表达；暂停状态不能还表现为持续运动。动画需服务状态、允许停止，并考虑减少动态效果的偏好。

## 大圆角与真实设备边界

- 尽早使用目标屏幕圆角并开启内容裁切。不能最后给展示图套圆角就宣称页面已适配。
- 同时检查上方时间、电量、左右边缘菜单、小时温度和底部按钮。矩形边距合格并不意味着位于圆角弧线内。
- 底部按钮上移时，连同上一排按钮和相邻数据一起调整，保持明确间隔。不要只移动最下面一行导致重叠。
- 检查照片、渐变、阴影是否越界，组件外壳和内部内容是否都正确裁切。
- 菜单、通知、详情、运动中、暂停、结束、天气昼夜都用同一屏幕边界验证；总览缩略图不足以证明所有屏幕安全。

## 常见症状 → 检查重点

| 反馈 | 优先检查 |
|---|---|
| 没设计感 | 比例、层级、留白节奏与图形语言，不先叠装饰 |
| 信息太少/太空 | 是否缺少用户必要数据，分区比例是否失衡 |
| 太多字/太生硬 | 重复说明、可视化机会、数据与单位关系 |
| 颜色违和 | 语义角色、强调色面积、背景对比，而非只换色相 |
| 图标不统一 | 可见轮廓重量、内外圆角、负空间、光学中心 |
| 列表别扭 | 卡片高度、单/双行垂直居中、底部露出方式 |
| 圆角后不美观 | 弧线安全区、底部操作、背景裁切和近边文字 |
