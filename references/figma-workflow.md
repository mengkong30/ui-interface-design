# 可编辑交付与工具经验

## 组件、状态与同步

- 建立可复用图标、按钮、开关、时间数字、菜单项及明确的状态变体；不要把所有不同页面粗暴塞进一个巨型组件。
- 若时间数字是图形，需要制作每个数字的字形与统一槽位，再组合小时、分钟和冒号状态。仅保留“10:08”一张图片无法支持变化。
- 天气状态覆盖产品需要的晴、多云、雨、夜间，以及加载、无数据等实际状态。按需求选择，避免无意义地给每个页面生成所有可能状态。
- 记录主组件、源页面、展示实例、变体和流程图之间的对应关系。修复共享内容优先改主组件；独立复制的源页面需显式同步。
- 隐藏备份的子节点可能仍标记为 visible。遍历时任何祖先隐藏都应剪枝；不能只检查叶节点可见性。也不要默认深入所有实例的大量历史子节点。
- 批量修改前限定目标类型和可见范围，保存修改记录；局部案例映射可以落盘，但不要把当前文件的节点 ID 写进通用技能。

## 本地 Figma 桥接经验

仅在使用对应工具时读其当前技能与能力说明。以下是本次已验证的机制，不保证未来版本相同：

- 先确认活动文件、页面和实时插件能力。读取工具列表少，不等于桥接不能写；可以有受支持的结构化本地命令。
- `update-node` 的支持字段可能少于创建节点接口。不支持的字段可能被静默忽略；回读实际属性验证，不以 HTTP 成功代替修改成功。
- 在本次桥接中，现有节点圆角通过数值变量绑定四个角字段完成。使用前确认支持 `design-system` 变量和绑定、字段与类型；不要为绕过限制擅自修改插件代码。
- 修改文字对齐/字体若不受更新接口支持，可以创建新文本、核对后隐藏原文本；保持内容、颜色和位置，避免丢失必要绑定。
- 实例只 resize 画框未必等于缩放图形。优先用保留比例的缩放机制；本次替换实例接口会按旧宽度缩放主组件，再保持原变换。
- 创建父画框时若子内容未全部完成，调用可能超时而实际已创建一部分。超时后读当前状态、定位部分结果再继续；不要立即重跑整段生成代码。
- 大批量变更适当拆分；保存新 ID 和阶段结果。独立读取可以并行，依赖性的创建、替换、隐藏和验证按顺序进行。
- 工具输出只打印必要字段，完整节点树存文件，避免大量隐藏备份与图片数据淹没上下文。
- 路径使用目标系统的有效形式。Windows 的 `C:/...` 不应误加前导斜杠变成 `/C:/...`。PowerShell 读写中文使用明确 UTF-8；shell 参数与 JSON 编码不是同一种转义。

## 视觉验证

- 导出实际 Figma 节点验证几何、文字、图标、阴影和裁切。生成工具成功不是视觉质量证明。
- 同时看单屏原始尺寸、需要放大的局部和整套总览；每种尺度解决不同问题。
- 对齐检查优先核对边界框和共同中心线，再检查轮廓的光学偏移；有长短变化的文本改用固定槽位居中。
- 批量替换后检查跨页面实例、不同滚动位置、天气昼夜以及流程图是否同步。
- 文本边界检查只能发现部分问题，不保证字号、光学对齐、色彩对比和弧线裁切都正确。

## 页面思维导图

用户要带实际页面的关系图时，以最新屏幕实例为节点，不只输出抽象文字树。

- 入口层级清楚：表盘/首页 → 应用总菜单 → 模块菜单 → 详情和操作状态。菜单新增后同步更新导航关系。
- 并列功能从共同父节点分叉，不串成错误的步骤顺序；连续任务使用有向链，例如准备 → 运行 → 暂停 → 总结。
- 暂停恢复、状态切换、系统来电等使用有意义的不同线型/标注，并给图例。系统来电不是某个普通菜单点击后的必经页面。
- 平行走线尽量不穿过画面和标签；交叉处用避让或清楚的无连接处理，不能让交叉线像汇合点。
- 返回手势、上下滚动等通用行为可放在统一图例，避免为每个屏幕绘制回线。
- 同一页面被多处引用时标明“共用页面”；复用主组件实例，避免静态截图随修改失效。
- 为中文名称预留文字区，缩略图按比例缩放，统一屏幕尺寸和圆角。跨模块分区和留白应让全图可扫描。
- 导图整理完成后核对节点清单、遗漏入口、分支和状态链。旧版可保留为隐藏备份；当前画板位置和名称应方便用户找到。
- 连接线代表设计关系，不自动等同于 Figma 原型绑定。没有完成实际绑定时明确说明。

## 导入与批量恢复中的具体故障

- 读取节点树再重建并不等同于复制：序列化可能遗漏 mask、vector paths、变换与裁切。整理天气等复杂图形时，用原图导出逐项比较；出现截断或层次缺失应先恢复原始图形，再谈重新设计。
- SVG 导入后需看实际结果。若 `stroke-dasharray` 圆环意外变成多段，按目标进度生成明确的圆弧路径；100% 使用完整圆。不要将导入错误当作有意的视觉风格。
- 创建超时后，节点存在不代表子节点已全部创建。对照预期子节点数量、关键标签与导出结果检查完成度，再补齐；保存每批检查点，避免重复整页创建。
- 验证共享组件变更时，至少检查一个当前页面实例。独立导入的 SVG 并不会随原主组件更新；应维持真实实例关系，或将独立副本明确纳入同步清单。
- 当前页与历史快照分区后，批量遍历限定当前根节点，并沿祖先可见性剪枝。不要因为隐藏备份内部节点仍是 visible 就重新改动旧稿。
