# 案例：轻量运动科技风智能手表

此处记录本次用户最终采用的方向。用于继续同类设计的起点，不覆盖新任务中的品牌、设备或交互要求。

## 产品与交互

- 定位：时尚、日常健康、轻运动，信息明确、减少评分压力。
- 表盘首页仅保留时间、日期/星期、天气/当前温度、步数、心率和电量；时间最大，其他信息次要。
- 屏幕为456×456，无真机外框。后来统一试配80px大圆角与真实内容裁切。
- 大标题居中加粗；用户要求手势返回，不设置页面右上角返回按钮；菜单不加方向箭头。
- 圆角矩形菜单一屏完整三项，卡片104px高、14px间距，32px图标配56px底板；滚动位置另有状态。数值按实际设备重新验证。
- 底部操作适配时将部分58px按钮移到y=374，留24px底部空间；这是起点，不保证任何形状在圆角屏上都安全。

## 色彩和图形

| 角色 | 案例颜色 |
|---|---|
| 页面背景 | #191C21 |
| 卡片 | #21252B |
| 次级表面 | #2B3039 |
| 主文字 | #F4F6FA |
| 次要文字 | #A7AFBD |
| 主色/主要操作 | #245BFF 钴蓝 |
| 活动/积极状态点缀 | #25ED91 绿色 |
| 心率/警示点缀 | #FF4058 红色 |
| 图表辅助蓝 | #6994FF |
| 图表浅蓝 | #C9D8F5 |

- 先前的天蓝、灰暗薄荷和多种额外点缀被用户否定；最终采用钴蓝主题、红绿点缀，辅以中性色。
- 一般图标是实际32px圆角面性、无描边。主视觉插画可更大；天气图标为64px明亮柔和插画，太阳可保留自然黄色。
- 小字号蓝字在深色底上辨识度不佳时，改成较亮的中性色或语义绿色，保留蓝色作为按钮和进度色。
- 天气使用照片背景和对比遮罩，取消重复的右侧大天气图标；小时预报继续保留图标。
- 小时预报以四个100px等宽槽位排布，起点x=28；每列时间、64px图标和温度共用中心线。固定槽位避免“13时”和温度偏左、太阳偏右。
- 展示板的图标名称、天气状态与说明统一中文，翻译后重新居中，不只替换字符串。

## 功能与状态清单

- 每日状态：步数、活动时长、目标、距离、当日健康摘要。多环分别表达实际指标，标明各自目标。
- 日常健康：心率、睡眠记录、久坐提醒、呼吸准备/练习中、可选生理周期记录。提醒可关闭或调整。
- 轻运动：步行、跑步、骑行、瑜伽、自由训练入口；以步行为示例制作准备、记录、暂停、总结状态。不要把示例步行流程说成所有运动细节均已完成。
- 生活助手：天气、消息列表/详情、来电、日程、闹钟、计时设置/运行、查找手机、音乐控制。
- 设置：表盘、振动、亮度、勿扰、睡眠模式、活动目标；细节设置可交给手机端。
- 新增应用总菜单覆盖五大模块，以顶部/底部两种滚动状态展示。
- 天气扩展晴天、阴雨、晴夜、多云夜晚；天气图标另有加载、无数据、离线、数据未更新等状态。

## 从反复修改中得到的经验

1. 主信息应先确定：增加步数、心率等数据后仍要保持时间占主导。
2. “高级感”不能靠低饱和灰色或随意渐变实现；统一颜色角色和空间比例更重要。
3. 列表形状、右侧箭头、返回按钮不能只按手机模板搬到手表。
4. 图标 keyline、内外圆角、轮廓重量应先统一，再批量替换页面实例。
5. 文字减少后，需要更清楚的图例、单位和对齐；不能让用户猜深睡与浅睡的颜色。
6. 单独修一屏不够：旧首页图标、流程图组件、天气变体、菜单末屏常被遗漏。
7. 大圆角应该参与布局验收，而不是仅美化展示；消息详情的双排按钮尤需检查。
8. 总菜单与导航图应跟随新增页面更新，导图要区分功能分支、操作顺序和系统事件。
