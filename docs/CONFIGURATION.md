# 配置方案

## 1. 基础配置：仅使用设计方法

1. 将发布包中的技能目录放入宿主的个人技能目录。
2. 确认 `SKILL.md` 直接位于该目录下，文件编码为 UTF-8。
3. 在技能列表中确认中文名称“ui界面设计”；调用标识为 `$ui-interface-design`。
4. 提供产品定位、目标设备/尺寸、页面范围、参考图和需要保留的约束。

基础使用无需 GitHub 登录、Figma 账号或 API Key。Git 只在采用克隆方式安装时需要；Python 只用于可选离线校验。

## 2. 自动选择与显式调用

默认保留宿主支持的自动技能发现行为。`agents/openai.yaml` 包含显示名称、简述和默认提示，不是执行程序。

若只希望手动调用，可在该文件中保留现有 `interface`，另外加入：

```yaml
policy:
  allow_implicit_invocation: false
```

显式调用仍使用 `$ui-interface-design`。不要把禁用自动发现误认为禁用了外部工具；工具权限由宿主单独管理。

## 3. Figma 配置方案

### 官方或其他受支持的 Figma 工具

在宿主的工具/插件配置中连接可信的 Figma 集成，授予任务所需的最小文件访问权限。提供准确文件链接或打开目标文档。读写、组件和原型能力取决于所安装工具，不能假定所有工具都有同一接口。

### 本地桥接方案

本技能不包含也不会自动安装桥接软件。用户应从可信发布者获取本地桥接工具，按其说明在 Figma Desktop 中启动插件，并保持目标文件打开。

执行前应完成：

- 检查活动文件和页面，避免改错文档。
- 读取运行中插件返回的实际能力；服务运行不等于 Figma 已连接。
- 仅对已确认的命令结构进行写入。
- 创建或修改后读取属性并导图核对，不能只相信返回成功。

`references/figma-workflow.md` 的桥接机制来自一个已验证环境，仅作为排错经验。端口、节点字段和命令可能变化，不应据此绕过工具权限或擅自修改插件。

## 4. 图片生成方案

使用宿主已有的图片生成工具即可。概念探索、天气照片与插画适合图片生成；组件、时间字形、图标系统和关系图优先采用可编辑内容。

若工具不可用，先完成不依赖图片的布局和规范，明确缺失的素材能力。不要假称已经生成或导入素材。提交参考图前检查其授权与敏感内容。

## 5. 推荐项目记录

在实际项目内维护简短记录即可，不要求固定文件名：

- 设备尺寸、屏幕圆角、主要任务和用户确认的风格。
- 颜色语义、字级、图标画板与真实尺寸。
- 主组件、页面实例、状态与流程图的对应关系。
- 已核对页面、未验证状态、当前导出和修改记录。

不要把账号密钥或私有客户资料写入公开技能。项目节点 ID 属于项目记录，不应加入通用技能正文。

## 6. 故障排查

| 现象 | 排查方式 |
|---|---|
| 看不到技能 | 检查目录层级、UTF-8、入口文件；按宿主机制刷新或新建会话 |
| 中文乱码 | 确认读取和写入均使用 UTF-8，避免重复转码 |
| 有技能但无法编辑 Figma | 技能不提供连接器；单独检查工具连接、账号权限和当前文件 |
| 修改返回成功但画面没变 | 回读节点属性，确认接口支持该字段、目标是否为可见实例 |
| 实例图形比例异常 | 区分画框 resize 与等比例缩放，检查主组件及覆盖值 |
| 工具超时 | 先读取是否已创建部分内容，再继续，避免重复提交 |
| 因权限限制不能写入 | 使用宿主正常授权流程或降低操作范围，不关闭安全保护 |
| 字体不可用 | 选择已授权、可用且支持中文的字体，重新核对文本宽度 |

## 7. 更新、回退与卸载

固定 `v1.0.0` 可避免默认分支变化。升级前保存本地定制；不要把自动覆盖当作安全升级。回退到此前验证版本后复查宿主兼容性。移除技能目录只停止该技能的发现，不撤销外部连接器权限，也不会自动恢复已编辑的设计文件。
