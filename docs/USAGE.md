# 使用说明

## 给出足够的任务上下文

优先说明设备、页面范围、主要用户任务、已认可的视觉方向和交付目标。若之前已确认过这些信息，要求助手沿用，不必重复调研。

```text
使用 $ui-interface-design。目标为456×456圆角手表屏幕，延续现有钴蓝主题，
只修复天气各列对齐与底部裁切，同步昼夜变体和流程图，完成后导出对比。
```

## 推荐使用流程

1. **收敛方向**：先确认信息优先级和少量代表页，不在方向未定时复制几十页。
2. **构建系统**：确定色彩角色、字级、间距、图标与组件状态；新页面沿用这些规则。
3. **局部迭代**：把问题定位到实际几何、比例或语义，同时查同类页面。
4. **设备验收**：在原始尺寸和真实圆角裁切下核对文字、图标、边缘与操作区。
5. **整理导航**：使用当前页面实例画出入口、并列功能、连续操作及系统事件。

这是可调整的流程；一个简单改色任务不需要走完整套流程。

## 任务示例

### 统一图标

```text
使用 $ui-interface-design 检查这组32px图标。保持面性、无描边、圆角，
以keyline和光学重量校正跑步、骑行、日历及音乐图标，然后替换页面实例。
```

### 减少文字并改善数据页

```text
使用 $ui-interface-design 优化数据页，突出主要数据，减少重复说明，
增加必要图表和图标，但保留单位、目标与睡眠阶段图例，不虚构数据。
```

### 圆角检查

```text
使用 $ui-interface-design 按目标设备圆角检查全部页面，重点看顶部时间、
底部按钮、列表末项和天气温度。修复时保留相邻元素的间距。
```

### 只审查，不编辑

```text
使用 $ui-interface-design 只做视觉审查，不修改任何文件。
列出具体问题、截图位置、影响和建议，区分已检查与未验证的状态。
```

## 如何验收

- 主信息一眼可识别，单位和辅助说明不会与其竞争。
- 同类图标实际尺寸一致，光学重量协调，内部圆角和孔洞清楚。
- 多列内容共享中心线，中文长度变化不造成偏移。
- 图表颜色有明确含义，必要图例存在；指标与目标可追溯。
- 设备弧线没有切到关键内容，底部操作留有空间且不会撞上上一行。
- 源页、主组件、状态变体与导图保持同步。
- 导图未把并列功能画成顺序操作，系统来电等事件被正确标注。
- 静态画面与真实原型的完成状态说明准确。

## 输出与限制
